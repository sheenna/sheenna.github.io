# Book Club live shelf - Supabase setup

The suggestion box works in "fallback" mode (opens a GitHub issue) until you plug in
Supabase. Once you do, every visitor's pick appears on the shelf for everyone, live,
with cover art. Free tier is plenty.

## 1. Create the project
1. Go to supabase.com, sign up, and create a new project (any name).
2. Wait for it to finish provisioning (~2 min).

## 2. Create the table + access rules
Open the project's **SQL Editor**, paste this, and run it:

```sql
create table if not exists public.book_suggestions (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now(),
  title text not null,
  author text,
  cover_id text
);

alter table public.book_suggestions enable row level security;

-- anyone can read the shelf
create policy "public read" on public.book_suggestions
  for select using (true);

-- anyone can add a suggestion (no login)
create policy "public insert" on public.book_suggestions
  for insert with check (true);
```

## 3. Turn on Realtime
Database > Replication (or the table's Realtime toggle) > enable Realtime for
`book_suggestions`. This is what makes new suggestions pop in without a refresh.

## 4. Paste your keys into the site
In Supabase: **Project Settings > API**. Copy two values:
- **Project URL**
- **anon public** key (the public one - safe to expose in front-end code; the
  row-level policies above are what keep it locked down. Do NOT paste the `service_role` key.)

In `preview-pages.html` (or `index.html` once live), find these two lines and replace
the placeholders:

```js
const SUPABASE_URL='__SUPABASE_URL__';
const SUPABASE_ANON='__SUPABASE_ANON_KEY__';
```

Save, reload. The box now writes to the shared shelf.

## Moderating
Instant-post means anything shows up until you remove it. To delete a suggestion:
Supabase > Table Editor > `book_suggestions` > delete the row. It disappears for
everyone on their next load.

## Notes / caveats
- The anon key is meant to be public, but only paste the **anon** key, never `service_role`.
- Instant-post has no spam gate. If it gets abused, tell me and I'll add a simple
  rate limit or flip it to a moderation queue (suggestions hidden until you approve).
- Covers and title search come from Open Library (no key, no account).

## Update (comments + live push)
Run this once in the SQL editor to add the optional note field and to guarantee
suggestions push live to other visitors (this second line is the fix if things only
appear after a refresh):

```sql
alter table public.book_suggestions add column if not exists comment text;
alter publication supabase_realtime add table public.book_suggestions;
```

If the second line errors with "already member of publication," that's fine, it just
means Realtime was already on. After this, the comment box saves and other people's
browsers update without a refresh. Your own submissions already appear instantly.
